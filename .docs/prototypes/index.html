Protótipos do MVP — 3 telas

Protótipos navegáveis, em HTML estático, das três telas essenciais do MVP (Fase 1 do documento de requisitos). Todos os dados são fictícios e gerados no próprio navegador; a consulta à SEFAZ é simulada, como o MockSefazGateway previsto para o backend. Servem para validar fluxo e regras de negócio antes da implementação em React + TypeScript + Tailwind + shadcn/ui + Recharts.

Como usar

  • Basta abrir os arquivos .html no navegador (duplo clique). Não há build nem servidor.
  • É preciso internet para carregar o Tailwind CSS via CDN.
  • Os dados reiniciam ao recarregar a página.

Para quem vai implementar

O visual segue o padrão do shadcn/ui (cards rounded-xl, bordas sutis, cinzas neutros) e os gráficos são SVG simples, fáceis de trocar por Recharts. Sugestões de componentes estão no README.md desta pasta.
